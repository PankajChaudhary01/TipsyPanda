# 🐼 Tipsy Panda

Tipsy Panda is a modern, responsive eCommerce web application for purchasing a wide variety of liquors online. Built using **React.js**, it features smooth navigation, product filtering by categories, and a clean, user-friendly UI.

![Preview](./src/Images/preview.pn)

## 🚀 Features

- 🛒 Browse and shop different liquor categories (whiskey, vodka, wine, etc.)
- 🔍 Search and filter products by type, brand, or price
- 📱 Fully responsive design for mobile, tablet, and desktop
- 💳 Add to cart and checkout UI (frontend)
- 🌙 Light/Dark mode toggle (optional)
- ⚡ Fast performance with optimized React components

## 🛠️ Tech Stack

- **Frontend**: React.js, React Router, Context API or Redux (if used)
- **Styling**: Tailwind CSS / CSS Modules / Styled Components
- **Icons & Assets**: FontAwesome, custom SVGs
- **Deployment**: Vercel / Netlify / GitHub Pages
